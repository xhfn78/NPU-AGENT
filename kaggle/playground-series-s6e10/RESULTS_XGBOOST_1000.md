# XGBoost 트리 1,000개 비교와 학습 시드 검증

2026-10-29 실행입니다. 사용자 요청에 따라 트리 수를 먼저 비교하고, 이후
XGBoost 학습 시드 1~41 검증을 모두 완료했습니다. 아래 점수는 고정 80:20 분할의 로컬 ROC-AUC입니다.
Kaggle 리더보드 목표 0.963 달성 여부와 구분합니다.

## 트리 수 비교 완료

데이터 분할 시드와 모델 학습 시드는 각각 42로 고정했습니다.
학습 559,708행, 검증 139,927행이며 외부 전처리와 93개 입력 특징도 동일합니다.
learning_rate=0.04, max_depth=6, min_child_weight=30,
subsample=0.9, colsample_bytree=0.9, reg_lambda=15, max_bin=512를 사용했습니다.

조기 종료 없이 실제 1,000개를 학습한 뒤 동일 모델의 앞부분 트리만 사용해 비교했습니다.

| 사용한 트리 수 | 검증 ROC-AUC |
|---|---:|
| 786 | 0.960275179 |
| 800 | **0.960275713** |
| 900 | 0.960266373 |
| 1,000 | 0.960246688 |

이 분할과 시드에서 1,000개는 786개보다 0.000028491 낮았습니다.
확인한 11개 지점 중 800개의 점수가 가장 높았지만, 786개와의 차이는 약 0.000000534로 작습니다.
이 한 번의 결과만으로 최적 트리 수를 일반화하지 않습니다.

동일 모델의 첫 786개 예측과 기존 786개 대조군의 예측은 최대 오차 0으로 일치했습니다.
1,000개 모델의 저장·재로딩 검사도 최대 오차 0이었습니다.
기록은 `outputs/xgboost_1000_trees/tree_comparison.json`과 `tree_comparison.csv`입니다.

## 시드 1~41 검증 완료 결과

| 1,000개 모델 기준 | 검증 ROC-AUC |
|---|---:|
| 대조군 시드 42 | 0.960246688 |
| 41개 개별 시드 점수의 평균 | 0.960280121 |
| 41개 개별 시드 점수의 표준편차 | 0.000042798 |
| 최저: 시드 17 | 0.960216598 |
| 최고: 시드 20 | **0.960396521** |
| 41개 시드의 확률을 평균한 예측 | **0.960391739** |

점수의 평균과 확률을 평균한 예측의 AUC는 다른 값입니다.
41개 확률 평균은 시드 42 대조군보다 +0.000145051이었습니다.

같은 시드에서 1,000개가 800개보다 높은 경우는 **11/41개**, 낮은 경우는 **30/41개**였습니다.
1,000개−800개의 AUC 차이를 시드별로 평균하면 **−0.000011217**입니다.
이 조건에서는 트리를 늘린 뒤 개별 시드의 성능이 일관되게 개선되지 않았습니다.

| 트리 수 | 개별 시드 AUC 평균 | 41개 확률 평균의 AUC |
|---|---:|---:|
| 786 | 0.960291831 | 0.960390475 |
| 800 | 0.960291338 | 0.960390757 |
| 900 | 0.960286738 | 0.960392357 |
| 1,000 | 0.960280121 | 0.960391739 |

확률 평균 후에는 800/900/1,000개의 차이가 작았습니다.
확인한 시드·트리 수 조합 중 가장 높은 관측값은 **시드 20, 800개, AUC 0.960411185**입니다.
이 조합도 같은 검증 데이터에서 선택한 탐색 결과이며 리더보드 개선을 확정하지 않습니다.

시드 1~41과 대조군 42의 저장 모델 42개가 실제 1,000개를 가진 것을 확인했습니다.
기록한 학습 시드와 XGBoost 학습 설정의 시드가 일치했고,
저장 모델 재로딩의 최대 예측 오차는 42개 모두 0이었습니다.
각 트리 수의 41개 평균 예측을 다시 계산해 저장된 배열과 AUC가 일치하는 것도 확인했습니다.

전체 점수표: `outputs/xgboost_1000_trees/seed_scores.csv`.
그래프: `outputs/xgboost_1000_trees/comparison.png`와 `comparison.svg`.

## 시드 실험의 조건

XGBoost에서 학습 시드 1~41을 모두 사용합니다. 대조군은 시드 42입니다.
각 시드에서 조기 종료 없이 1,000개를 학습하고, 같은 모델의 786·800·900·1,000개 시점도 평가합니다.
데이터 분할, 외부 전처리, 학습률, 깊이 등 다른 조건은 고정합니다.
실제로 사용된 학습 시드는 XGBoost의 저장된 학습 설정에서 확인해 기록합니다.

시드별 최고 점수, 평균·표준편차, 41개 시드의 확률 평균을 비교합니다.
또한 각 시드에서 800개와 1,000개를 짝지어 비교해, 트리 증가 효과가 반복되는지 살펴봅니다.
시드 최고값은 동일 검증 데이터에서 선택한 탐색 결과이며 독립 평가나 리더보드 개선의 증거가 아닙니다.

원래 세 모델을 준비한 `validate_seeds.py`는 시드 42의 대조군 3개만 실행했습니다.
사용자 우선순위 변경 후 범위 실험은 `xgboost_1000.py`의 XGBoost에 적용합니다.

## 실행과 파일

```powershell
cd C:\study\kaggle\playground-series-s6e10
& C:\Users\Admin\miniconda3\envs\ml311\python.exe xgboost_1000.py trees
& C:\Users\Admin\miniconda3\envs\ml311\python.exe xgboost_1000.py seeds
```

두 단계를 함께 실행하려면 `xgboost_1000.py all`을 사용합니다.
현재 준비된 고정 분할 특징과 대조군을 재사용합니다. 이 캐시를 새로 준비하려면
`validate_seeds.py pilot`을 먼저 실행합니다. 원본 파일, 전처리 코드, 설정의 해시를 확인합니다.
완료한 시드는 다시 실행할 때 예측과 저장 모델을 재사용합니다.
그래프를 다시 만들려면 같은 환경에서 `python plot_xgboost_1000.py`를 실행합니다.

`outputs/xgboost_1000_trees/`의 산출물:

- `tree_comparison.csv`, `tree_comparison.json`: 시드 42의 트리 수 비교.
- `seed_scores.csv`: 모든 시드의 트리 수별 검증 AUC.
- `seed_summary.json`: 시드 범위, 통계, 평균 예측 AUC, 800/1,000개 짝 비교.
- `seed_XX.json`, `seed_XX_metrics.json`: 시드별 1,000개 모델과 실제 학습 시드/재로딩 검사.
- `seed_XX_validation.npy`, `seed_XX_trees_*_validation.npy`: 시드·트리 수별 검증 확률.
- `all_41_seed_mean_trees_*_validation.npy`: 41개 시드의 평균 검증 확률.
- `manifest.json`: 원본/특징/설정 해시와 고정 비교 조건.

이번 단계는 검증 실험이며 새 Kaggle 제출 파일은 생성하지 않습니다.
